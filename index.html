Python Solution (Dutch National Flag)


class Solution:
    # Time Complexity: O(n)
    # Space Complexity: O(1)
    def sortColors(self, nums):
        low = 0
        mid = 0
        high = len(nums) - 1

        while mid <= high:
            if nums[mid] == 0:
                nums[low], nums[mid] = nums[mid], nums[low]
                low += 1
                mid += 1
            elif nums[mid] == 1:
                mid += 1
            else:  # nums[mid] == 2
                nums[mid], nums[high] = nums[high], nums[mid]
                high -= 1

Algorithm Strategy

This uses the 3-way partitioning logic (Dutch National Flag problem). We maintain three pointers: low for 0s, mid for 1s, and high for 2s.

Complexity

This solution performs a single pass through the array O(N) and swaps elements in-place with constant extra space O(1).
